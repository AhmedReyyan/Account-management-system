<h2  align="center">Functionalities</h2>
 <li>Secure Login Access </li>
 <li>Limited Access according to Roles</li>
 <li>User can view the company details and other users and add expenses to the company's budget</li>
 <li>Every company has its own admin</li>
 <li>Admin credentials can't be seen by users but only by administrators </li>
 <li>Admin can approve the expenses submitted by users or reject them </li>
 <li> Administrators have access to every company and can do every task that  an admin can do  </li>
 <li>Only the Administrator can add new companies and set their credentials and admin</li>
 <li>Admin and Administrator both can add new users and edit their details</li>
